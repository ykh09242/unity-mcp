# `scene` tools

GameObject positioning, placement and scene diagnostics

- **[`gameobject_duplicate`](./gameobject_duplicate.md)** — Duplicate a GameObject with optional name, parent and position changes.
- **[`gameobject_placement`](./gameobject_placement.md)** — Preview or apply alignment and distribution of selected GameObjects.
- **[`gameobject_positioning`](./gameobject_positioning.md)** — Move or orient a GameObject selected by target (or name). move_relative requires reference_object plus direction or offset; look_at requires look_at_target.
- **[`scene_reference_diagnostics`](./scene_reference_diagnostics.md)** — Inspect scene references within explicit work and result budgets.
- **[`scene_validate`](./scene_validate.md)** — Validate the scene, with optional explicit repair.
