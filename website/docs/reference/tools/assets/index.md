# `assets` tools

Asset changes, labels, bundles and reference diagnostics

- **[`asset_bundles`](./asset_bundles.md)** — Inspect asset bundles, their contents and dependencies.
- **[`asset_edit`](./asset_edit.md)** — Create, import, modify, duplicate, move or delete assets and folders.
- **[`asset_labels`](./asset_labels.md)** — Read or change asset labels with revision checks.
- **[`asset_reference_diagnostics`](./asset_reference_diagnostics.md)** — Inspect dependencies and reverse references, or preview asset moves and deletion.
- **[`manage_reference_graph`](./manage_reference_graph.md)** — Maintain an automatic asset/code/external-config reference graph for the selected Unity instance and authenticated user.
