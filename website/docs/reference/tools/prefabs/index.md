# `prefabs` tools

Prefab creation, contents, stages and overrides

- **[`capture_prefab`](./capture_prefab.md)** — Render a prefab asset to PNG in an isolated preview scene, then clean up.
- **[`prefab_contents`](./prefab_contents.md)** — Edit prefab contents, inspect whole-prefab or selected-component changes without saving with modify_contents preview_only and preview_scope, or preview and apply a guarded transform change.
- **[`prefab_create`](./prefab_create.md)** — Create a prefab asset from an existing GameObject.
- **[`prefab_overrides`](./prefab_overrides.md)** — List prefab overrides, trace a serialized property through variants, or apply or revert selected overrides.
- **[`prefab_stage`](./prefab_stage.md)** — Open, save or close the Prefab Stage.
