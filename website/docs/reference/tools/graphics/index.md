# `graphics` tools

Rendering, lighting, volumes and graphics diagnostics

- **[`manage_light_baking`](./manage_light_baking.md)** — Control light baking and configure light or reflection probes.
- **[`manage_render_environment`](./manage_render_environment.md)** — Inspect the environment or configure skybox, ambient light and sun.
- **[`manage_render_fog`](./manage_render_fog.md)** — Enable or configure scene fog.
- **[`manage_render_pipeline`](./manage_render_pipeline.md)** — Inspect the render pipeline or change quality and pipeline settings.
- **[`manage_render_reflections`](./manage_render_reflections.md)** — Configure environment reflection mode, intensity, bounces and resolution.
- **[`manage_render_volumes`](./manage_render_volumes.md)** — Create volumes and profiles, then inspect or configure post-processing effects.
- **[`manage_renderer_features`](./manage_renderer_features.md)** — Add, configure, reorder or remove URP renderer features.
- **[`manage_rendering_stats`](./manage_rendering_stats.md)** — Inspect rendering counters and memory, or select a scene debug view.
