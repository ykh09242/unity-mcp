# `camera` tools

Camera setup, Cinemachine and view capture

- **[`capture_camera`](./capture_camera.md)** — Capture Game or Scene views, including surround and orbit batches.
- **[`manage_cameras`](./manage_cameras.md)** — Create or list cameras, select targets and configure lenses or priority.
- **[`manage_cinemachine`](./manage_cinemachine.md)** — Configure Cinemachine brains, tracking, extensions and camera blends.
